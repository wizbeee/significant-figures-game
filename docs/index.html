동전 밀도 실험 시뮬레이션

오차 전파를 직접 따라가 봐요
50원 동전 2개의 밀도를 구해 봐요. 단계별로 다음 버튼을 누르며 오차 전파를 확인하세요.
이게 다음 차시 수행평가의 핵심이에요.
📋 측정 데이터
📋
측정값 (동전 2개, 1회 시행)
동전 질량 m = 8.3204 ± 0.0001 g (분석저울)
초기 부피 V₁ = 11.55 ± 0.05 mL (눈금실린더)
나중 부피 V₂ = 12.51 ± 0.05 mL (눈금실린더)
1 동전의 부피 = V₂ − V₁
측정값: 12.51 − 11.55 = 0.96 mL
절대불확정도(덧/뺄셈은 절대값 합): 0.05 + 0.05 = 0.1 mL
→ V = 1.0 ± 0.1 mL
📌 측정값과 불확정도의 끝자리를 맞추기 위해 0.96 → 1.0으로 반올림
2 상대불확정도로 변환
질량: 0.0001 / 8.3204 = 0.0000120…
부피: 0.1 / 0.96 = 0.10417…
📌 곱·나눗셈은 상대불확정도로 변환해서 계산해요
3 상대불확정도의 합
0.0000120 + 0.10417 = 0.10418
📌 곱·나눗셈에서는 상대불확정도를 더해요
4 밀도 계산 = m / V
8.3204 / 0.96 = 8.667 g/mL
📌 동전의 부피는 0.96(원래 계산값)을 그대로 사용해요
5 절대불확정도로 재환산
8.667 × 0.10418 = 0.9029 g/mL
📌 상대불확정도(0.10418) × 측정값(8.667)으로 절대불확정도를 구해요
🎯 최종 결과
d = 8.7 ± 0.9 g/mL
💡 실제 50원 주화의 밀도는 약 8.7 g/mL(백동 합금)이니 측정값은 잘 맞았어요. 그런데 불확정도가 ±0.9, 무려 10%나 돼요. 왜 그럴까요? — 3단계를 다시 보면 상대불확정도의 99.99%가 부피에서 왔어요. 동전 2개의 부피(약 1 mL)가 눈금실린더의 읽기 오차(±0.05 mL)에 비해 너무 작아서예요. 질량은 분석저울로 재서 기여가 거의 0이고요. → 동전 개수를 늘려 부피를 키우거나, 더 정밀한 부피 측정 기구를 쓰면 불확정도가 줄어요. 7번 섹션의 측정 기구 고르기가 바로 이 이야기예요.
